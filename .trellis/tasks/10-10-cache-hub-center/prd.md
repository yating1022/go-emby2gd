# 大盘鸡缓存中心（hub）

> 父任务：持有需求全集、任务地图与跨子验收，不直接实现。
> 子任务：`10-10-hub-agent-mode`（hub 模式）、`10-10-hub-master-integration`（master 接入）、`10-10-hub-deploy-verify`（部署与真链验证）。

## Goal

把 VPS.Twon（香港大盘鸡：250G 数据盘、到四节点 RTT 0.7–2.3ms、节点实拉 36–118MB/s、月流量 3T）建成全网唯一的回源缓存中心：

- **master 在浏览/播放入口下预热指令**（不再是"戳边缘"），携带直链与区域集；
- **hub 从 Google 回源、磁盘落盘**（48h TTL + LRU 硬上限），路过即存、全文件渐进；
- **节点播放时从 hub 明文内网口拉流中继**（边缘对 hub 无感）；
- **hub 不可达 → 回退直连 Google**（现状不变）。

目标收益：Google 的 ~0.5–1s 固有初始化从「每节点每次」降为「全网每文件一次，且发生在**浏览时刻**」；播放探测全集命中磁盘 → 起播探测 TTFB 毫秒级。

## Background（2026-10-10 讨论 + 实测）

- Twon 实测：`/home` 250G（249G 空闲）、2C/2G、无 IPv6；到 VIMESS/酷网云/家人云/Zouter RTT 1.0/2.3/0.8/1.2ms；节点从它拉 256MB：59/36/61/118 MB/s；家 NAS→Twon 210ms（**不可接客户端**）；Twon→dl.google.com 96MB/s；**Twon→googleapis 间歇性连接卡死**（部分 A 记录连不通，9 测 5 次卡 7.5–22.5s）。
- 家 NAS vantage：边缘节点 →googleapis 稳定（conn 2–66ms、ttfb ~0.5s）；起播 = 3–6 个探测请求 × 每个 ~0.5–1s Google 固有初始化。
- 用户定：**48h 缓存有效期**；月流量 3T 够；**角色区分**——普通 agent = 客户端中继（代理大盘鸡缓存的流），大盘鸡 = 中心（唯一回源点）；**预热须覆盖播放探测全集**；**多 hub 后续要兼容**；不引第三方组件（rclone 已否决，用自家直链）。
- v0.3.2 已有能力直接复用：单流切片预取、让路、断点续取、三态（空/部分/满）服务。

## Requirements（全集）

- **N1 角色**：hub 为注册进现有 agent 网络的第二角色（`role: hub`），不参与客户端调度、不接客户端；注册表/选择函数支持多实例（本次只部署一台）。
- **N2 数据面**：hub 对内明文 HTTP（不签名不加密），确定性 URL `/f/<driveFileID>`；拉流口/控制口仅对 master + 四节点 IP 白名单开放；三态服务（空→回源透传、部分→前缀先行混合、满→磁盘直供）复用节点侧逻辑与字节一致性保障。
- **N3 缓存策略**：磁盘块存储于 Twon `/home`；全文件渐进填充；**48h TTL**；**磁盘 LRU 容量硬上限**（防爆盘，200G 档）；头段先行（预算即停）、**真实播放开始才续全量**、3 分钟无播放停止（hub 侧自维护，master 可发 cancel）。
- **N4 预热范围=播放探测全集**：头段（单流切片，默认 128MiB）+ 尾部 cues 区（默认末 4MiB）+（master 已知续播点时）续播偏移附近（默认 ±4MiB）。
- **N5 节点侧**：master 把上游指向 hub URL 时节点照常透传（对 hub 上游不附 Google Authorization）；保留内存 L1（头块）兜底。
- **N6 master 侧**：注册表 role；hub 选择函数（现单 hub 平凡策略，结构上 fileID 哈希→多实例）；预热改向（沿用浏览触发点，目标=hub）；播放上游=hub URL（warm 被接受才用，否则 Google 直链）；回退链：指令失败/hub 不可达→现状直连。
- **N7 回源加固**：hub 回源实现多 A 记录快速失败拨号（单地址 ~1.5s 超时切换）——必须（实测踩雷 7.5–22.5s）。
- **N8 凭据**：缓存命中供流不需要凭据（不出网）；回源用 master 下发的直链（Authorization ~1h），过期用换新链+断点续传接住。

## Acceptance（跨子任务）

- [ ] **A1 起播**：真链、家庭 vantage——浏览后播放：探测 TTFB 毫秒级、不触 Google；秒点播放（浏览后 2s 内）起播目标 ≤5s 再降。
- [ ] **A2 缓存治理**：48h TTL 到期失效、LRU 上限生效、盘余量稳定（不爆）。
- [ ] **A3 一致性**：三态服务字节一致性矩阵全绿；混合前缀先行；hub→Google 断网时命中供流仍工作。
- [ ] **A4 回退**：hub 停机/不可达时播放自动走 Google 直链，体验=改造前（故障演练验证）。
- [ ] **A5 多 hub 预留**：注册表与选择函数支持多实例（代码+测试层面；不要求部署第二台）。
- [ ] **A6 流量**：Twon 月流量观察在 3T 内（头段先行 + 3 分钟规则压住浏览浪费）。
- [ ] **A7 零回归**：node 角色行为不回归（v0.3.2 全量对照）；hub 不参与客户端调度（调度测试覆盖）。
